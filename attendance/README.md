# 勤怠管理（休暇調整）シート

正社員2名 + 派遣2名の少人数チーム向けに、誰がいつ休むかを一箇所で見える化し、
出勤人数が最低ラインを割らないように調整するためのスプレッドシート。

- `勤怠管理_休暇調整シート.xlsx` … 生成済みのファイル（Googleスプレッドシートにそのままインポート可）
- `build_attendance_sheet.py` … 生成スクリプト（`pip install openpyxl` の上で `python3 build_attendance_sheet.py`）

## シート構成

| シート | 役割 |
|---|---|
| シフト表 | 年・月を切り替えるだけで自動生成される月間一覧。日ごとの出勤人数と判定（OK / NG / 要注意）を表示 |
| 休暇申請 | 唯一の入力元。1休暇1行。状態を「承認」にするとシフト表と有給管理へ反映 |
| 有給管理 | 承認済みの有給を基準日以降で自動集計。年5日取得義務のチェック付き |
| 設定 | メンバー、勤務曜日、営業曜日、記号、最低出勤人数、祝日 |
| 使い方 | 運用手順と運用ルールの例 |

## 判定ロジック

- 出勤人数 = その日に勤務予定のメンバー数から、承認済みの休み（半休は0.5）を引いた値
- 最低出勤人数（既定 2名）または最低正社員出勤人数（既定 1名）を割ると NG
- 申請中の休みも休み扱いで再計算した「承認した場合の判定」を別行で表示（要注意）
- 土日祝と設定シートの休業日は判定対象外
