# 挿絵の扱い

基準デッキには「困っている担当者」「トロフィー」「散らばった書類」などの挿絵が、資料の内容に合わせて入っている。
挿絵は **資料ごとに変える**。使い回しの汎用イラストは置かない。

## 置ける場所（outline.json の `image` フィールド）

画像は **正方形** で作る（縦横比が違うと余白の中に収まるだけで、欠けはしない）。

| 型 | フィールド | 置かれる位置 | 表示サイズ（px @1920） |
|---|---|---|---|
| cover | `image` | 右側中央。文字は左寄せに切り替わる | 560 × 560 |
| statement | `image` | 一言主張の右側。主張は左に寄る | 480 × 480 |
| compare | `left.image` / `right.image` | パネル右上（主張・本文の右） | 220 × 220 |
| before_after | `before.image` / `after.image` | パネル右上 | 220 × 220 |
| case_flow | `before.image` | Before パネル右上 | 220 × 220 |
| case_kpi | `side.image` | 右カード（アイコンの代わり） | 360 × 360 |

値は画像ファイルのパス（PNG / JPG / SVG。outline.json の場所からの相対パス）。`build_deck.py` が `assets/illustrations/` にコピーして配置し、`--pptx` の pptx にも同じ位置で埋め込む。指定が無ければピクトグラムのまま。
1 資料に入れるのは cover・statement・case_kpi のような「大きく見せる 3 枠」を優先し、パネル右上の小枠は補助として使う。

## 挿絵の作り方（生成 AI を使うとき）

このスキルは画像を生成しない。手元の画像生成ツールで作り、`scripts/check_illustration.py` でブランド色に収まっているか確認してから使う。

プロンプトの型（そのまま使える）:

```
フラットなベクターイラスト、日本のビジネスシーン、[場面: 例 紙とExcelとメールに囲まれて困っている事務担当者]。
背景は白（#FFFFFF）または無地。配色はティール #00979C、濃ティール #006A6D、イエロー #F9BB00、
薄いティール #EBF7F7、グレー #657A7B のみ。輪郭線なし、影は薄いティール。文字・数字・ロゴを描き込まない。
人物は日本人、表情は控えめ。正方形、余白多め。
```

- 場面は **ヒアリングの言葉** から作る（「FAX で来た解約通知を Excel に打ち直す」なら、その絵）。
- 1 資料に 3 点まで。Before 側は暗めのグレー多め、After 側はティール多めにすると対比になる。
- 文字が描き込まれた画像は不可（後から直せない。ブランド書体でもない）。
- 生成物は `assets/illustrations/<案件名>/` に置き、outline.json からパスで指定する。

## 検査

```bash
python3 scripts/check_illustration.py path/to/image.png
```

不透明ピクセルのうち、ブランド色（ティール系・イエロー系・ニュートラル）から外れた色相の割合を出す。15% を超えたら差し戻す。肌色は例外として扱う。
