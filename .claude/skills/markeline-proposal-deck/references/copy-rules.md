# 言い回しの規則

トーンは MARKELINE の brand voice（信頼感がある／フランクだが軽すぎない／経営者に刺さる／実務的／相手を責めない）。

## タイトル帯（主張文）の型

| 型 | 例 |
|---|---|
| 対比 | 現場のやり方は変えない。こちらが合わせる |
| 数 + 共通点 | 課題は4つ。どれも「人に依存」している |
| 現状の言い切り | 毎日、時間とお金が溶けている |
| 順序 | 小さく始めて、効果を見ながら広げる |
| 金額 + 比較 | 月額30万円。増員するより、仕組みに投資する |
| 実績の証明 | 実績①：“現場を変えずに”成果が出ている |

NG: 「料金」「実績」「進め方」「現状」だけのラベル。「〜について」「〜のご説明」。

## 結論帯（黄 or ティール）

- 「＝」で始めると「つまり」の意味になり、上の内容の要約に見える。「＝ コスト削減“だけ”でなく…」
- 引用符を使って相手の言葉を返す。「『使ってください』ではなく『一緒に作りましょう』。」
- 1 文。40 字以内。強調語は 1 箇所だけ黄色（ティール帯の中）。

## 数字

- 相手が言った数字だけ使う。単位を必ず付ける（時間・分・名・万円・件・%）。
- 範囲は「2〜3時間」「15〜20分」のように波ダッシュ。「約」は相手が概算と言ったときだけ。
- 推定・仮置きは「（例）」を付ける。料金が未確定なら「※ 金額は例。実際の見積はヒアリング後にご提示します。」を必ず入れる。
- 効果の数字は「Before → After」の形（3〜4時間 → 15分）。「〜%削減」より「〜分になった」の方が現場に刺さる。

## 相手の言葉を使う

- ヒアリングの固有名詞（賃貸名人、GPT有料、駐車場の消し込み、シュレッダー）はそのまま。一般語に丸めない。
- 部署名・役職名はヒアリングどおり。「現場」「事務」「担当者」の使い分けも相手に合わせる。

## 禁止・注意

- 「無料」「今だけ」「限定」「激安」「業界No.1」（根拠のない優位性）。
- 補助金・助成金の断定（「使えます」→「活用できる可能性があります。要件の確認が必要です」）。
- 他社・既存ベンダーの否定（「従来のDX」は仕組みの話であって、相手の過去の判断の否定ではない）。
- 実績の社名は掲載許可が確認できたものだけ。無ければ業種表記（「広告代理店」「サービス運営業（介護施設）」）。
- 「弊社」より「MARKELINE」「私たち」。相手は「御社」。
