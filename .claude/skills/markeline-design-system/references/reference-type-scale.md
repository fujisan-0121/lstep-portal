# 参照タイプスケール（野村工務店様 ご提案 実測）

基準資料「野村工務店様 ご提案」（14枚、画像化スライド 2046×1151px）から、役割ごとに文字の高さをピクセル実測し、
Noto Sans JP Black で同じ文字を描いて校正した比率（和文 0.97、数字 0.775、"1,000" 0.99）で font-size に換算した。
単位は **1920px 幅換算の px**。pt は Google スライド標準（720pt 幅）換算で px × 0.375。計測スクリプト: `scripts/measure_reference.py`。

## 読み取れる設計思想

- **ジャンプ率が極端。** 見出し 80〜120、数字 160〜230 に対して本文は 24〜33。「見出しと数字だけ読めば分かる」設計。
- 本文 24〜27px は投影では小さい。基準資料もそこは同じなので、採用値の下限を **24px** に置く（注記のみ）。それより小さい文字は作らない。
- 結論帯は本文の 2 倍以上（64）。帯の中の強調語は色を変えるだけで、サイズは変えない。
- タイトル帯は 1 行 22 字に収まる範囲で 88。収まらないときは 72 まで下げる。それでも入らない文言は短くする。
