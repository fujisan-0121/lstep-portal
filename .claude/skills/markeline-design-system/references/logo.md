# ロゴ

## ファイル

| ファイル | 用途 | 中身 |
|---|---|---|
| `assets/markeline_logo_color.png` | 白系背景（`paper` `bg` `teal-50` `yellow-50`） | 2250×1600 透明 PNG。ティール `#00979C` とイエロー `#F9BB00` の 2 色のみ |
| `assets/markeline_logo_white.png` | ダーク面（`teal-800` `teal-900` `ink` `brand-black`、`brand-teal` の面） | 同サイズ、`#FFFFFF` 単色 |
| `assets/markeline_logo_master.pdf` | 印刷入稿・拡大が必要なとき | デザイナー納品ベクター。CMYK 85·8·39·10 / 0·32·100·0 |

Illustrator 原本（`logo_color.ai` / `MarkLine_logo_data.ai`）は Google Drive `画像・ロゴ・マスコット/MarkLine_logo_ロゴ/ai_data/` にある。SVG 化が必要なら原本から書き出す。**文字を打って再現しない。トレースもしない。**

## 構造

- シンボル: 4 つの丸いアームが中央で組む「H」型。左アームがティール、右アームがイエロー。
- ワードマーク: `MARKE`（イエロー）+ `LINE`（ティール）、丸ゴシック系欧文、全大文字。
- 縦組み（シンボル上・ワードマーク下）が唯一の公式レイアウト。横組み版は存在しないので作らない。横長スペースにはシンボル無しでテキストの `MARKELINE` を置くのではなく、縦組みロゴを小さく置く。

## 寸法とクリアスペース

- PNG 2250×1600 のうちアートワークは (300,271)〜(1950,1330) = 1650×1059 px。アスペクト比 1.558。
- 四周の透明余白は左右 300px（アート幅の 18%）、上下 約270px（アート高さの 25%）。**この余白がクリアスペース。** PNG の外接矩形に他要素を接触させなければ規定を満たす。
- 最小サイズ: デジタル 120px 幅（アートワーク幅ではなく PNG 幅）、印刷 25mm 幅。それ以下では `LINE` の細部が潰れる。
- スライド (1920×1080) の定位置: 右上または左下、PNG 幅 160〜200px。LP ヘッダー: PNG 高さ 64px（実アート約 42px）。スライドのフッター: PNG 高さ 44px。PNG の余白込みなので、見た目より数値を大きめに取る。

| 背景 | カラー版 | 白版 |
|---|---|---|
| `paper` `bg` `teal-50` `yellow-50` | ○ | × |
| `teal-800` `teal-900` `ink` `brand-black` | × | ○ |
| `brand-teal` の面 | ×（LINE が消える） | ○ |
| `brand-yellow` の面 | ×（MARKE が消える） | ×（コントラスト不足） |

## 禁止

- 縦横比変更、回転、ドロップシャドウ、縁取り、グラデーション、透過、色替え、モノクロ化（黒版は master.pdf にあるが、Web では使わない）。
- ロゴの一部（シンボルだけ、ワードマークだけ）の切り出し。ファビコンが必要ならシンボル単体は **原本 .ai から書き出す**。
- ロゴを見出しの代わりに使う（「MARKELINE のサービス」の `MARKELINE` をロゴ画像にしない）。
- 他社ロゴと並べるとき、MARKELINE ロゴを相手より小さくする。同じ高さに揃える。

## HTML での置き方

```html
<img src="assets/markeline_logo_color.png" alt="MARKELINE" width="180" height="128" decoding="async">
```

`alt` は `MARKELINE`。装飾的な繰り返し（フッター 2 回目など）は `alt=""`。`width/height` は 2250:1600 の比を保つ（180×128、225×160、270×192）。
