# タイポグラフィ

## 書体

| 用途 | 書体 | ウェイト | 読み込み |
|---|---|---|---|
| 和文・本文・見出し | Noto Sans JP | 400 / 500 / 700 / 900 | Google Fonts（`tokens.json > google_fonts_url`）またはセルフホスト |
| 数値・KPI・日付・ページ番号・ラベルキャップス | IBM Plex Mono | 500 / 600 / 700 | 同上 |
| 巨大数字・KPI（インフォグラフィック型） | Noto Sans JP | 900 | `--ml-font-display`。sans と同じ書体で、基準資料「野村工務店様 ご提案」の数字表現に合わせる |

書体は和文 1 種 + 等幅 1 種だけ。基準資料を拡大して確認した書体が源ノ角ゴシック系（Noto Sans JP）の Bold/Black だったため、2026-09-02 に Zen Kaku Gothic New から切り替えた。「資料と同じ見え方」が最優先なので、他の Google 日本語フォント（Zen Kaku、M PLUS、BIZ UD 等）に勝手に戻さない。

Office 系（pptx / docx / xlsx）は環境にフォントが無いと置換される。`tokens.py` の `FONT_SANS_OFFICE_FALLBACK`（Yu Gothic）と `Consolas` を代替として `latin` と `eastAsia` の両方に明示する。
Calibri / Arial / MS Pゴシック / メイリオを残さない（`lint_tokens.py` が検出する）。

CSS の font-family は必ず `var(--ml-font-sans)` / `var(--ml-font-mono)` を使う。文字列で書き直さない。

## mono の鉄則

`IBM Plex Mono` は ASCII しか持たない。`<span class="mono">1,200万円</span>` のように和文を含めると、
「万円」だけシステム等幅にフォールバックして字面が崩れる。数値と単位を分ける。

```html
<span class="mono">1,200</span><span class="unit">万円</span>
```

単位は sans、サイズは数値の 60%、色は `sub`。

## 和文の組み方

- 1 行 40 字前後で折る（本文 max-width 640px 目安）。LP 本文が 700px を超えて横に伸びていたら幅を絞る。
- `text-align: justify` を使わない。中央揃えは見出しと CTA だけ。本文は左揃え。
- 見出しは `<br>` で意味の切れ目で改行し、単語の途中で折り返させない。`word-break: keep-all; overflow-wrap: anywhere;` を見出しに当てる。
- 約物（「」（）、。）は詰めない。半角英数の前後に空白を入れない（`MARKELINEの`、`LINE公式`）。
- 数字は半角。金額は `1,200万円`、割合は `83.6%`、日付は `2026-09-01` か `2026年9月1日`。
- 英字の社名表記は `MARKELINE`（全大文字）。和文表記は `マーケライン`、正式名称は `株式会社MARKELINE`。

## ジャンプ率

見出しと本文の比は最低 2 倍。スライドは 1 枚の最大要素が必ず見出しか KPI 数値。
「少しだけ大きい」中途半端なサイズ（本文 24 に対して見出し 28 など）を作らない。
