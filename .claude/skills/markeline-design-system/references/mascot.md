# マスコット「マーケラトプス」

トリケラトプスをティール系で描いたキャラクター。Google Drive `画像・ロゴ・マスコット/マーケラトプス/` に `mt1.png`〜`mt6.png`（1773×1772 透明 PNG、2021-12）。
このスキルには代表 1 点 `assets/mascot_marketops_01.png` を同梱。他ポーズは Drive から取る。

マスコットの色はブランド原色と**一致しない**（ティールが明るく緑寄り、黄も明るい）。これは仕様。
マスコットの色を UI に流用しない。逆に、マスコットを `brand-teal` に塗り直さない。

## 使いどころ

- LINE 公式アカウントのプロフィール、リッチメニューの案内役、社内資料の吹き出し、FAQ の話者、404 ページ。
- 経営者向け提案書・見積書・契約書体裁には出さない（信頼感優先。ブランドボイス「軽すぎない」）。
- 1 成果物に 1 体。並べない。
- 背景は `paper` か `bg` か `teal-50`。ダーク面では輪郭が沈むので `paper` の丸座布団（`radius pill`）を敷く。
- 最小サイズ 96px。吹き出しは `line` 1px 枠、`radius md`、文字は `ink`。
