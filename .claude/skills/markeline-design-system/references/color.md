# 色の使い方

数値はすべて `tokens/tokens.json`。ここでは「どの場面でどれを選ぶか」だけを決める。
コントラストは `tokens/contrast.md` が正で、このファイルの数字はそこからの転記。

## 役割マップ

| 役割 | トークン | 備考 |
|---|---|---|
| ページ背景 | `bg` `#F4F6F6` | 純白ページは `paper`。両方を交互に使ってセクションを分ける |
| カード・スライド面 | `paper` | 枠は `line` 1px、上辺アクセント `brand-teal` 4px |
| 標準文字 | `ink` `#1C2122` | 見出しも本文もこれ |
| 補助文字 | `sub` `#657A7B` | キャプション・注記・表の出典。白地で 14px 以上 |
| ブランド文字（白地） | `teal-600` `#008085` | リンク、ボタンのテキスト、小見出し。本文サイズならこれ以上濃く |
| ブランド文字（濃く） | `teal-700` `#006A6D` | 6.40:1。長文の強調やホバー |
| 大見出し・面・アイコン | `brand-teal` `#00979C` | 24px 以上、または太字 18.66px 以上。本文には使わない |
| 淡面 | `teal-50` / `teal-100` | 表ヘッダ、チップ、引用背景、帯 |
| ダーク面 | `teal-900` → `teal-800` → `ink` | ヒーロー、フッター、反転バナー。文字は `paper` |
| CTA 面 | `brand-yellow` | 文字は `ink`（9.41:1）。ホバー `yellow-600` |
| ダーク面の強調文字 | `brand-yellow` | `teal-900` 上で 8.87:1、`ink` 上で 9.41:1 |
| 白地の黄系文字 | `yellow-700` `#B38700` | 3.29:1 なので 24px 以上の見出し限定。原則は使わない |
| 強調セル | `yellow-50` | 表の合計行、注目 KPI の背景 |
| 減少・リスク | `danger` `#D8472B` | 白地で 4.32:1。18.66px 太字以上か、アイコン併用 |

## イエローの総量規制

イエローは「行動」の色。1 画面（1 スライド、LP の 1 ビューポート、1 バナー）に**役割は 1 種類**だけ。

- LP: ヒーローの CTA ボタンと固定フッターの CTA ボタンは同じ役割なので OK。それに加えて見出し下線にも黄色、はダメ。
- スライド: KPI 4 つのうち最重要の 1 つだけ `yellow-50` 面。他は `teal-50`。
- バナー: CTA 帯か、キャッチの 1 語のマーカー（`yellow-100` 下線）か、どちらか。

面積の目安は画面の 5% 以下。超えたら「安売りチラシ」になる。ブランドボイスの「安売り感を出さない」はここに直結する。

## ダークとライトの切り替え

- ライト基調が標準。LP 全体、スライド本編、帳票。
- ダーク（`teal-900`）は「決意・結論・締め」の場面に 1 回。LP ならヒーローかクロージング、スライドなら表紙と最終メッセージ。
- ダーク面のロゴは必ず `markeline_logo_white.png`。

## チャート配色（順序固定）

系列 1 `brand-teal`、系列 2 `teal-400`、系列 3 `teal-200`、系列 4 `sub`、強調したい 1 系列だけ `brand-yellow`。
軸・グリッドは `line`、ラベルは `sub`、数値は mono。負の値・悪化は `danger`。
5 系列を超えるなら図を分ける。多色パレットを作らない。

## やってはいけない色

- `#888` `#999` `#ccc` `#eee` `#f5f5f5` などの純グレー。ニュートラルは全部ティール相。
- 緑（成功にも使わない）、青、紫、ピンク、オレンジ。「オレンジ」と口頭で呼ばれることがあるが、実体は `#F9BB00` のイエロー。
- 黒 `#000000` を文字に。文字は `ink`。`brand-black` はモノクロロゴ専用。
- グラデーション。面は単色。どうしても必要なら `teal-900 → teal-800` の同相 2 段のみ。
- 半透明の白/黒オーバーレイ。写真の上に文字を置くときは `teal-900` の帯を敷く（`rgba(0,42,44,.85)` は `teal-900` の透過なので可。他色の rgba は不可）。
