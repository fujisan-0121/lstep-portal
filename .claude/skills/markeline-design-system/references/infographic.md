# インフォグラフィック提案書スタイル（提案書・セミナー資料の標準）

基準サンプル: 「野村工務店様 ご提案」（Google Drive, 2026-06, 14枚）。クライアント提案・セミナー投影・営業資料はこの型で作る。
`references/slides.md` の余白多めの編集誌風は、社内向け・報告書・議事録など「読む資料」に使う。迷ったらこちら（インフォグラフィック）。

土台は `templates/infographic.html`（1920×1080、8 種の型を実装済み）。コピーして中身を差し替える。

## 最優先ルール: 1 枚 1 メッセージ、文字は大きく

投影されるスライドは「読む」ものではなく「見た瞬間に分かる」もの。会議室の後ろの席からでも読めることを基準にする。

- **タイトル帯はラベルではなく主張文**。「料金」ではなく「月額30万円から。増員より圧倒的に安い」。タイトルを読むだけで結論が伝わる。
- **1 枚に載せる主張は 1 つ**。根拠ブロックは 2〜4 個まで。5 個以上になったら枚数を増やす。「8 枚くらい」と言われても、1 枚 1 メッセージが守れないなら 10〜12 枚にしてよい。
- **文字サイズは `references/reference-type-scale.md`（基準資料の実測）が正。** 目安: タイトル帯 88、見出し 78、結論帯 64、カード見出し 52、本文 27〜33、注記 24（下限）、一言主張 170、KPI 数字 184、料金 176、なぜ今の番号 230。テンプレートの CSS はこの値になっている。
- 下限は 24px（1920×1080 基準）。それより小さい文字は作らない。基準資料もこの下限で作られている。
- **箇条書きはカード 1 つにつき 1〜2 項目、1 項目 1 行**（全角 22 字以内）。説明したくなったら次の枚へ。
- **表は 4 行まで、列は 3 列まで**。それ以上は 2 枚に割る。
- 余白は詰めない。文字を大きくして要素が入らないなら、要素を減らす。フォントを小さくして入れるのは禁止。
- 数値は 1 枚に 1 つの「主役の数字」。比較する数字は 2 つまで。

## この型の性格

- 1 枚で「主張 + 根拠 + 結論」が完結する。上にタイトル帯、中に根拠（カード・数字・表・図）、下に結論帯。
- 情報密度は高いが、要素は 3〜6 個の「ブロック」に必ず束ねる。ブロックの外に浮いた文字を作らない。
- 数字が主役。KPI は 96〜160px の巨大数字で、単位は小さく添える。
- ティール = 帯・面・番号・アイコン。イエロー = 結論帯・強調数字・マーカー・矢印。**この型ではイエローを 1 枚に複数回使ってよい**（結論帯 + 強調 1〜2 語 + 矢印まで）。ただし面積は画面の 15% 以下、黄色の面が 2 つ並ぶ配置は避ける。
- 挿絵はフラットな単色ピクトグラム（`brand-teal`）か、写真風イラスト 1 点まで。文字入り画像は作らない。テキストは必ず HTML テキスト。

## 1 枚の骨格

```
titlebar  120px : teal-700 面、白 900 44px のタイトル。右端を 60px の斜めカット（clip-path）。左上に白い角丸ボックス + カラーロゴ（ボックス 200×120、PNG 高さ 100）
body            : 左右 72px、上下 32px。ブロックを grid で配置。gap 24〜32px
conclusion 120px: brand-yellow 面（ink 900 36px）か teal-700 面（paper 900 36px + 強調 brand-yellow）。左にチェック丸（teal-700 / paper）
```

タイトルはロゴの右から始める。タイトル帯とロゴボックスが重なるときはロゴボックスを前面に。

## 文字

- 見出し・本文: `Noto Sans JP`。タイトル帯 88/900、見出し 78/900、カード見出し 52/900、本文 27〜33/700、注記 24/500（下限）。全て実測値（`references/reference-type-scale.md`）。
- 締めの一言（まとめ最下段）だけ `Noto Serif JP` 900（`--ml-font-serif`）。基準資料の唯一の明朝。他では使わない。
- 巨大数字: `Noto Sans JP`（display = sans と同一） 700（`--ml-font-display`）。`IBM Plex Mono` はこの型では使わない（投影距離で等幅は硬く見える）。ページ番号だけ mono 可。
- 24px 未満を作らない（注記・ページ番号のみ 22px 可）。投影前提。
- 強調は 3 手段だけ。①`.marker`（`yellow-100` の下地帯）、②`yellow-700` の文字、③`teal-700` の文字。赤や下線は使わない。

## イエローの display 例外

参照デッキの「1,000万円」のように、白地で `brand-yellow` の巨大数字を置くのはこの型の署名的表現。WCAG では 1.73:1 で不合格なので、次の条件を全部満たすときだけ許可する。

- 96px 以上、weight 700 以上
- 同じ行に `ink` のラベル（何の数字か）が必ずある
- 1 枚に 1 箇所
- 印刷物・Web ページには使わない（投影スライドとバナーのみ）

条件を満たせないなら `yellow-700`（3.29:1）か、`brand-yellow` の面に `ink` の数字（9.41:1）に切り替える。

## アイコン

- `templates/infographic.html` の `<svg><symbol>` スプライト（clock / users / yen / check / calendar / bulb / arrow / doc / phone / chart / building / car）を `currentColor` で使う。色は `brand-teal`、結論帯の中は `teal-700` か `paper`。
- 線幅 2.5〜3（viewBox 24 基準）。塗りアイコンと線アイコンを 1 枚に混在させない。
- 絵文字を使わない。フォント依存で環境ごとに変わる。

## 作り方の手順

1. 提案の骨子を「1 枚 1 主張」で 8〜14 枚に割る。表紙 → ゴール → 現状 → 数字 → 一言 → 考え方 → 具体策 → 効果 → 進め方 → 料金 → 実績 → まとめ。
2. 各枚に上表の型を割り当てる。同じ型を 3 連続させない。
3. `templates/infographic.html` の該当 section をコピーして文言を差し替える。数字は確認済みのものだけ。未確認は「例」を付ける。
4. `python3 scripts/lint_tokens.py --strict deck.html`、`python3 scripts/render_preview.py deck.html --preset slide_16_9 --each .slide` で全枚を見る。
   納品時は最高画質で出す: `--scale 2` で 3840×2160 の PNG、`--pdf` でベクター PDF（文字が埋め込まれ、拡大しても劣化しない）。画像貼り込みの pptx や JPEG 圧縮のスライドは作らない。
5. はみ出し・2 行に折れたタイトル・24px 未満の文字・1 枚に主張が 2 つある枚を直す。直し方は「削る」か「枚を割る」。縮めない。
6. pptx が必要なら `references/slides.md` の python-pptx 手順で同じトークンを渡す。画像貼り込みの pptx にはしない（編集不能になる）。
